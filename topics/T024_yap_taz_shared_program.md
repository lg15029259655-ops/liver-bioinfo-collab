# 课题卡：yap_taz_shared_program

日期：2026-11-18（全文、方法和输入覆盖核查日期）。  
来源：论文反推；Wang 等，2021，PMID：[33232824](https://pubmed.ncbi.nlm.nih.gov/33232824/)，DOI：10.1016/j.jcmgh.2020.11.008。  
反推范围：原文 TCGA 的 YAP1/WWTR1 共表达与功能富集分析，不把细胞双敲实验算作患者分析。已读取开放全文、Fig.8 和人体方法；“我的复核取舍”与作者实际方法分列。YAP 为蛋白常用名，对应基因 YAP1；TAZ 对应 WWTR1，不能混入符号为 TAZ 的其他基因。

## 1. 课题（一句话）
人 HCC 中 YAP1 与 WWTR1 的共表达基因是否支持一个稳定共享的细胞周期程序，而非固定取前 2500 个基因造成的表观重叠？

## 2. 研究目的类型
□ 描述　■ 关联　□ 预测　□ 机制

评估两个表达相关程序的一致性，不能仅凭相关和 GO 富集确定共同直接靶基因。

## 3. 独立单位与比较对象
以 TCGA 患者为独立单位，各患者提供一个肿瘤表达向量；比较两个种子基因的相关排序与功能解释。两个排序来自同一批患者，不是两个独立队列；基因是特征，不是患者数量。

| 数据层次 | 核对结果 | 对设计的影响 |
|---|---|---|
| 原文公共分析 | TCGA PanCancer Atlas；分别按 Spearman 排序取 YAP/TAZ 正相关前 2500 基因，进行 GO 分析 | 2500 是作者截断规则，不是通过校正的显著基因数 |
| 原文软件 | 方法写 edgeR 3.28.1 作 GO 分析、VennDiagram 1.6.20、ComplexHeatmap 2.2.0 | 没有写清本次可复算的具体 GO 函数、背景、校正家族和全部过滤参数，不能自行补成原文既定步骤 |
| 当前可用表达 | YAP1/WWTR1 均有 366 位患者有限值；矩阵 20531 行基因均为有限值 | 有限值不等于基因有足够变异；全零或恒定特征仍应按预定规则过滤 |
| 原文局部组织队列 | Table 1 为 27 例较好预后、37 例较差预后，共 64 人；Human HCC Samples 段却写 37+37 | 存在人数文字矛盾，不能按 74 人扩样，也不能把预后类别人数当死亡数 |
| 原文核染色口径 | 结果段先报 YAP 36、TAZ 41、双阳 16、任一阳性 61/64，后面单阳标签与前面边际人数不一致 | 标签须结合原图和患者表核对；本卡不选择一个口径擅自修复 |
| 突变、配对与事件 | 本题不按突变分组、不依赖癌旁配对、不使用生存结局，均不适用 | IHC、预后及细胞实验只作解释边界，不能加入共表达样本分母 |

**当前结论：366 人表达矩阵足以开展新的共表达稳健性评价；原文 2500 基因集合的精确复现仍缺完整输入定义。** 共表达富集最多提供共享程序的关联支持，不能单独确认 YAP 与 TAZ 的功能可互换或药物作用相同。

## 4. 分析清单

| 序号 | 分析（清单编号） | 做什么 | 为什么需要 | 项目里有没有 |
|---|---|---|---|---|
| 1 | A1 公共人体共表达 | 原文分别求 YAP/TAZ 与 TCGA 基因的 Spearman 相关，取前 2500 | 找出各自相关程序并比较总体一致性 | T830 有共表达核心，但默认只输出前后各 20，需适配完整排序 |
| 2 | A2 固定多种子分析汇总 | 原文对 YAP 与 TAZ 平行重复相关和功能解释 | 避免只显示有利于“共享”的一个种子结果 | 没有完整批量汇总，需统一种子、背景和输出 |
| 3 | 清单里没有：共表达列表 GO 富集 | 原文对两个相关列表进行 GO 分析，解释细胞周期等共同过程 | 将列表相似与功能相似分开呈现；这不是 A5 的单样本通路活性评分 | 有富集部件，但原背景和具体函数未落实，不能直接写成已复现 |
| 4 | 清单里没有：排序/集合重叠分析 | 原文使用 Venn 图与热图展示相关基因和表达模式 | 展示共享与特有部分，避免只列共同术语 | 没有带患者重抽样、阈值敏感性和匹配背景的通用配方 |

**需要判断的难点：** 从同一表达背景各取 2500 个基因，本来就可能获得较多重叠；而相同 GO 大类并不意味着由同一批直接靶基因驱动。YAP1 和 WWTR1 的表达相关、两者自身混入对方列表、共同增殖/纯度信号，都可能增加重叠。因此必须审查具体基因和背景，而非把两张富集柱状图相似当作功能等同。

我的复核取舍：冻结 log2(RSEM+1)、患者清单、非恒定基因背景，先移除两个种子自身，输出完整相关系数排序。原文前 2500 规则独立复现；新增稳健性比较用前 1000、2000、2500 三个预先指定位置，不挑最支持共享的一档。相关和富集的多重检验分别按完整基因背景、两个列表的 GO 检验家族处理，不将未经校正的“前列基因”写为显著靶标。

再按患者重抽样检查共有基因与主要功能方向是否稳定，登记取样后经常消失的“特有”基因。若进行匹配随机列表，应匹配表达量/变异度，不能用大量低表达基因作容易通过的背景。共享程序主要反映增殖时，结论应写为“共同增殖相关”，不能上升为两个蛋白完全冗余；条件化处理增殖评分是敏感性检查，也可能移除真实下游效应，不能当成唯一裁决。

## 5. 这个课题回答不了什么

- 不用两份前 2500 名单交集冒充因果靶基因，不把相关排名直接转换为基因调控方向。
- 不将 RNA-seq 的连续相关分析硬套成两组 DESeq2；没有计数和真实组别时不伪造差异表达输入。
- 不用两个 GO 大类都显著来证明 YAP 与 TAZ 可互相替代；原文细胞/动物结果属于另一种证据。
- 不选 WGCNA、LASSO、随机森林全套筛选来重复同一问题；当前是两个固定种子的程序比较，不是新建候选模型。
- 不凭当前两篇论文都报 64 人就称为独立组织验证；患者来源关系未核清前要防止跨论文重复。

## 6. 可能的竞争解释

肿瘤纯度、细胞周期、基质比例及分化谱系可驱动共同相关。GO 术语层级重叠会让不同基因列表得到相同名称；表达尺度、背景过滤与较大的固定列表也会改变结论。某个基因未进前 2500 可能只是排名第 2501，而不代表它是另一个种子专属程序的反证。

## 7. 你不确定的地方（写“待定”）

- 待定——原集合复现：候选是取得原补表及过滤参数后精确重做，或使用当前 366 人快照做新评价。前者可核对原图但输入尚缺，后者可审计完整排序却未必还原旧名单。我的倾向是两者分开命名，因为数据冻结改变后不能以重叠数不一致直接判原文错误。
- 待定——共享判据：候选是仅看固定名单交集，或同时比较排序、功能和患者重抽样稳定性。前者直观但高度依赖截断，后者更稳健却需更多输出和解释。我的倾向是后者，因为真正共享的信号不应只在一个任意名次边界出现。
- 待定——增殖影响：候选是只报告总体共表达，或增加独立来源增殖评分的条件化敏感性。前者保留总关系但难排除共同增殖，后者可检验特异性却可能移除真实生物下游。我的倾向是总关系为主、条件化单列，因为不能把调整后的消失简单解释成“没有共同功能”。
