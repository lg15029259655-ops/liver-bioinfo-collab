来源：围绕仓库团队主题拟题，AI 辅助修订稿；不是论文反推卡，也不是已经运行的分析结果。

## 1. 课题（一句话）
HBV 相关 HCC 患者的治疗前 VCAN 表达是否与实际免疫检查点治疗客观缓解相关？

## 2. 研究目的类型
■ 关联。只问真实治疗队列中的表达—缓解关联；删除旧卡中同时追问病因差异、免疫分型、细胞来源等多个问题的安排。

## 3. 独立单位与比较对象：先查数据
| 内容 | GSE140901 实际核查 |
|---|---|
| 人数与病因 | 24 个样本；HBV 19、HCV 3、Other 2；按患者而非基因或细胞计单位 |
| 实际 best_response | 全体 PR 6、SD 10、PD 8；HBV 子集 PR 4、SD 9、PD 6；未出现 CR |
| 本题比较 | HBV 子集 PR 4 对 SD/PD 15；不要将 SD 自动算入客观缓解 |
| 标签区别 | clinical_benefit_response 全体 Yes 13/No 11，与 PR 6/非 PR 18 不是同一终点 |
| VCAN 可测性 | 对 SOFT 中 GPL19965 的平台目标表检索 VCAN 及旧名 CSPG2，命中 0；该免疫面板没有本题目标 |
| 事件 / 突变 / 配对 | 终点是客观缓解，4 是 HBV 缓解例数，不是死亡数；突变例数不适用；不是治疗前后配对设计 |

**结论：这个课题现在做不了，因为可公开取得的 GSE140901 面板不含 VCAN，且 HBV 子集中只有 4 例客观缓解。** 不能用 TCGA 的 VCAN 表达与另一个队列的疗效标签拼成患者数据；本轮没有确认另一份同时具备 VCAN、HBV 病因和实际疗效的公开匹配队列。

## 4. 分析清单与判断难点
| 分析 | 做什么 | 为什么需要 | 现有能力 |
|---|---|---|---|
| A4 病因分层 | 使用原始 etiology 字段先限 HBV，保留 HCV/Other 及缺失的区别 | 定义本题目标人群，防止把 Other 填成 NASH | 缺病因统一规则 |
| A9 ICI 响应验证 | 仅在存在匹配目标表达与真实标签的队列评价效应、区间与判别表现 | 真实疗效检验的前提 | 没有通用配方；当前被可测性阻断 |

判断难点：换成全 24 人或换成“临床获益”会增加阳性标签，却改变研究问题，也不能修复 VCAN 缺测。建议保留不可行结论，不用 TIDE 分数冒充真实缓解。

## 5. 回答不了什么；哪些分析不该做
不要做 HBV/HCV/Other 三组分层建模，HCV 只有 3 人、Other 只有 2 人；不要用 4 个 HBV 缓解病例训练多变量分类器；不要补造 VCAN、插补一个整列未检测基因、或把非肝癌疗效队列当 HBV-HCC 临床验证。

## 6. 竞争解释
既往治疗、取材时间、肿瘤组织中基质比例与病因相关，可能同时影响 VCAN 和治疗结局；关联也不必然是药物特异获益。

## 7. 未决选择（每项三句话）
- 待定——替代数据：候选为寻找/申请同时有全转录组、HBV 和真实疗效的 HCC 队列，或把课题改成 TCGA 中 VCAN 的免疫评分关联。前者能回答原问题但可能受数据访问与样本量限制，后者容易取得却只能回答另一个观察性问题。AI 倾向保留原卡并暂停，因为改变终点应另立新卡，不能悄悄降格为临床疗效证据。
- 待定——未来疗效定义：候选为 RECIST 客观缓解，或持续稳定也计入的临床获益。前者较清楚但事件更少，后者依赖持续时间和评估规则且与客观缓解不同。AI 倾向客观缓解，因为本卡已锁定这一问题，同时必须取得原文评估口径后再实施。
