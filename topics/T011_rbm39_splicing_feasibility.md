# 课题卡：rbm39_splicing_data_feasibility

日期：2026-11-18（数据与文献核查同日）。  
来源：围绕仓库团队主题拟题，AI 辅助修订稿；不是论文反推卡，也不是已经运行的分析结果。  
作者个人判断：尚未由作者本人填写或确认；下文所有“建议”“倾向”和停止决定均为 AI 建议，供作者作出自己的判断。

## 1. 课题（一句话）
当前项目是否具备检验人胆管癌 RBM39 表达与预指定剪接事件 PSI 关联的处理后数据条件？

## 2. 研究目的类型
■ 描述。本卡直接回答数据可行性，不执行冻结中的剪接生物学分析；B2 的分析实施仍按仓库要求等待项目负责人放行。

## 3. 独立单位与比较对象：先查数据
| 条件 | 已查情况 |
|---|---|
| 公开来源存在性 | 官方 TCGA SpliceSeq 提供按癌种下载处理后 PSI，下载页列有 CHOL，不需要自行比对 FASTQ |
| 表达端已审核 | cBioPortal CHOL PanCancer Atlas 2018 有 36 名患者、36 个肿瘤表达样本，RBM39 有 36 个值；这只是表达端，不是 36 个有合格 PSI 的患者 |
| 项目已提供输入 | 本会话收到 0 份项目 PSI 表、0 份事件注释表、0 份已锁定的候选事件清单；当前可审计的表达—PSI 匹配患者为 0 |
| 不能冒充的数字 | 数据库有 CHOL 选项不等于某事件有足够非缺失患者；文献纳入人数不等于本事件实际可用 n |
| 事件数区别 | 尚未锁定任何具体剪接事件，候选事件数为 0；这里“剪接事件”与死亡事件不同，本卡无生存终点 |
| 突变 / 配对 | 不做突变分组，突变人数不适用；目标是同患者表达—PSI 匹配，不要求肿瘤/癌旁配对 |

**结论：这个课题现在做不了，因为尚无匹配的处理后 PSI、事件定义和预指定事件，且 B2 尚未获项目实施放行。** 此卡是合格的停止判断，不以总 RNA 表达代替剪接，也不因有数据库页面就声称已具备分析数据。

## 4. 分析清单与判断难点
| 分析 | 需要的内容 | 为什么需要 | 现有能力 |
|---|---|---|---|
| B2 RNA 剪接 | 放行后取得处理后 PSI 与事件坐标、类型、基因、缺失规则；匹配 RBM39 表达及患者 | PSI 才对应剪接使用比例，基因总表达不是同一读出 | 没有；原始比对不在项目范围 |

判断难点：若先在全基因组搜索与 RBM39 最相关的事件，再把该事件当预指定验证，会产生明显的选择偏倚。建议将发现与验证拆开登记，当前不选一个显著事件来填空，数据不足时保留不可行结论。

## 5. 回答不了什么；哪些分析不该做
不做原始测序重比对，不以外显子总读数替代 PSI，不在少量 CHOL 患者中筛上万事件后报告未经校正的最佳相关，不把 RBM39—PSI 相关写成 RBM39 直接调控剪接的因果机制，也不擅自启动被冻结的 B2。

## 6. 竞争解释
肿瘤纯度、细胞比例、测序覆盖和缺失过滤可同时影响 RBM39 与 PSI；关联也可能来自同一细胞类型富集。

## 7. 未决选择（每项三句话）
- 待定——事件来源：候选为从独立功能研究预指定一个坐标明确事件，或在 CHOL 内先探索全部合格事件。前者减少选择偏倚但需要已核实的直接证据，后者能发现线索却需全家族校正及独立重复。AI 倾向前者，在没有合格事件来源前维持停止，因为本卡目标是可检验的明确假设。
- 待定——实施范围：候选为待项目负责人放行后下载处理后 PSI，或目前只登记公开来源与缺口。前者能推进生物学分析但当前授权范围尚受冻结要求限制，后者不能产生相关结果却符合此轮可行性审查。AI 倾向后者，因为这次反馈要求覆盖卡片，并未明确解除 B2 的实施冻结。
