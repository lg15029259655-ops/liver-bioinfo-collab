# 说明书：B5 多方法机器学习候选基因筛选

## 0. 基本信息
- 清单编号：B5；类别：一（公开数据足够，优先在HCC开展；胆管癌须单独核实）。日期：2026-11-20。
- 状态：有待定项。本文件规定候选基因筛选、独立验证和交接给A1/A2的可复现流程；不报告本项目新候选基因或新模型结果。
- 目标：在一个预先指定的人类肝癌问题中，把差异表达（DE）、WGCNA模块关联、LASSO、随机森林（RF）和SVM-RFE按无信息泄漏的训练/验证边界串联，得到稳定候选基因及其证据等级。算法交集是优先级排序，不是因果证明。
- 首选疾病问题：成人原发HCC肿瘤与非肿瘤肝组织的候选诊断标志物筛选；病因、分期等可作预先指定的敏感性分析。iCCA不与HCC合并；只有样本数及病理注释达门槛时才单独复制流程。
- 现有配方：仓库工具清单列有差异表达、WGCNA、LASSO/预后模型等工具，但未证明上述五个筛选环节已形成一条有独立验证和无泄漏控制的B5流水线。现有工具可复用其输入/输出接口，不得把“工具存在”写成“此分析已完成”。
- 本任务只提交Markdown说明书；不上传数据、代码、论文PDF或个人信息。

## 1. 要回答什么问题
在预先指定的HCC患者肿瘤与配对/非配对非肿瘤组织中，哪些表达基因同时具备差异证据、与疾病表型相关的共表达模块支持，并在LASSO、RF、SVM-RFE等互补筛选器中表现出可重复的判别信息？这些候选在独立患者队列中能否保持方向和判别能力？

主要估计目标是患者层面的肿瘤/非肿瘤判别。此流程本身不证明预后价值、治疗响应、机制或临床诊断效用。若实际研究问题是生存预后，不得把肿瘤/正常标签替换为OS后沿用分类流程；需另行预注册生存结局、删失和事件数，且不把诊断标志物称为预后标志物。

### 2.1 患者级数据清单
建立 `B5_cohort_manifest.tsv`，每行一个样本，至少记录：study/accession、匿名patient ID、sample ID、组织类型（肿瘤/癌旁/正常/未知）、癌种和解剖部位、原发/转移、配对关系、平台与RNA工作流、表达单位、临床字段可用性、纳排状态/理由、研究来源、处理版本及访问日期。建立 `B5_patient_split.tsv` 保存患者所属训练折或外部队列。若患者身份无法跨accession去重，独立性记“待定”，不声称独立验证。

**主分析进入条件：**HCC组织学与样本来源可判断；发现集至少80例肿瘤患者，若做肿瘤/非肿瘤判别则每类至少30个独立患者/样本；外部验证至少30例可评价肿瘤患者，并有同平台对应非肿瘤对照才可报告外部诊断分类性能。配对肿瘤-癌旁的差异分析至少30对。上述门槛仅用于避免极小样本机器学习，不代替预注册的功效分析。若没有适格外部对照，改报告方向复核与限制，不计算看似精确的外部诊断性能。

### 2.2 表达矩阵与注释冻结
- RNA-seq差异分析使用原始整数counts并用DESeq2或limma-voom；不得对TPM直接输入DESeq2。WGCNA及机器学习使用log2(TPM+1)或vst/rlog等适宜变换；记录转换方式。不同平台不直接拼接归一化矩阵。
- 芯片数据保留平台探针到Entrez/Ensembl/HGNC的可追踪映射。一个基因对应多个探针时，按平台说明预先选择唯一映射规则；不得看结果后挑探针。重复探针可用中位数汇总并做敏感性检查。
- 低表达过滤规则固定为：在至少20%肿瘤样本中原始counts≥10（RNA-seq）；芯片则以平台检测/背景校正和表达分布的预先固定规则过滤。跨验证队列仅取训练集可映射基因的交集；缺失特征比例>20%则停止冻结模型迁移，不以外部数据插补训练模型特征。
- 记录基因组注释版本、ID映射表、过滤前后基因数、每一步患者数、批次、肿瘤纯度可用性。不得将临床缺失标签编码为阴性。

## 3. 分析步骤

### 3.1 预先定义比较与分割
主分析为HCC肿瘤 vs 对照肝组织的二分类诊断筛选。先将患者分成训练开发集80%和内部锁箱集20%，以患者为单位、按组织标签分层，固定种子 `20261120`；成对样本必须整体分组。外部队列整体封存，不参与候选筛选、阈值选择、特征缩放、模型调参或候选数量决定。若TCGA-LIHC数据已被分析者反复查看，则内部锁箱只用于程序审计，不能宣称完全独立确认；独立GEO/ICGC队列仍是主要外部证据。

### 3.2 差异表达与候选预过滤
- 若配对样本足够，主差异模型使用患者配对阻断/配对设计；否则采用非配对设计，并在模型中纳入预先指定且可用的批次/协变量。肿瘤/癌旁分析的估计对比与协变量写入 `B5_preregistration.yaml`。
- 采用DESeq2或limma-voom估计log2FC、标准误、原始P值与BH q值；主要候选预过滤为BH q<0.05且绝对log2FC≥0.5。报告所有通过表达过滤的基因检验数。若队列混合多个平台，逐研究分析，不对原始强度直接合并。
- 差异过滤在训练开发集内完成。测试折和外部验证均不得用于决定差异基因名单；内部交叉验证中，每个训练折需重新拟合差异过滤，避免全数据预筛导致信息泄漏。

### 3.3 WGCNA模块支持
- 只在发现队列训练开发样本、按预注册方式处理批次后建网。优先使用肿瘤样本内表达变异关联预定临床表型；肿瘤与非肿瘤混在一起容易因组织类型驱动模块，故不得将“癌/正常差异”造成的模块解释成肿瘤内共表达机制。
- 按样本数和基因数决定是否运行：训练肿瘤样本≥80、表达过滤后基因数充分时才运行探索性WGCNA。软阈值选择遵循近似无尺度拟合与平均连接度折衷，记录所有候选power及诊断图；不把固定power视为普适真值。采用signed network、bicor（存在离群值时）或Pearson作为主设定，minModuleSize=30，deepSplit=2，模块合并阈值`mergeCutHeight=0.25`，并报告参数敏感性。
- 模块-表型关联报告相关系数、置信区间/P值和BH q值。只有预先指定表型相关q<0.05的模块作为支持证据。模块内候选排序使用module membership与gene significance的连续值，不事后用“hub gene”挑阈值。
- 在每个内部训练折重新建网；如果计算成本或子样本量不允许稳定构网，WGCNA只作为全训练集探索性证据，不进入交叉验证预测流水线，并明确说明这一差别。

### 3.4 三个机器学习筛选器
候选池为训练数据中的表达过滤基因与DE候选的并集（并集规则在全部训练折内重新执行）。主筛选任务为肿瘤/对照分类，RF和SVM-RFE以患者标签为目标。每个筛选器均在重复嵌套交叉验证的训练部分内运行；推荐外层5折×5次重复、内层5折。若最小类别/患者数不足以构造这些折，则降为外层分层3折并报告，不得把患者随机拆散。

| 方法 | 预设执行方式 | 候选判定依据 |
|---|---|---|
| LASSO logistic | `glmnet`二项模型；标准化参数仅由训练折估计；内层交叉验证选择lambda.1se为主，lambda.min为敏感性；alpha=1 | 基因在外层训练重采样中的非零系数选择频率；同时报告系数方向/分布，不只报告一次拟合的系数 |
| Random Forest | 固定实现与版本，分类森林；在内层折调mtry及节点最小样本数，树数至少1000或OOB误差已稳定；类别不平衡采用训练折权重/平衡抽样并作未平衡敏感性 | 使用训练折内置置换重要性或permutation importance；避免仅依赖有偏的Gini重要性。报告重复抽样排序稳定性 |
| SVM-RFE | 线性SVM递归特征消除；特征缩放和RFE完全在训练折执行；内层CV选择特征数，搜索候选数按对数/分段网格并在配置文件冻结 | 外层训练折中入选频率和排名分布；不以全样本SVM-RFE筛出的基因回头进行CV |

### 3.5 集成与候选等级
- 每个基因形成五类证据：DE支持、WGCNA模块支持、LASSO稳定选择、RF稳定排序、SVM-RFE稳定选择。一个算法里基因名重叠不能被重复计为独立证据。
- **核心候选（Tier 1）：**在≥70%的外层训练重采样中被至少2/3个机器学习方法选中或进入预先确定的RF重要性前10%，并且方向在至少一个独立外部表达队列一致；另需通过ID映射和样本独立性检查。若外部队列无法访问，只能称“发现集优先候选”，不能升Tier 1。
- **支持候选（Tier 2）：**有DE/WGCNA支持且至少一个机器学习方法稳定入选，但未达到Tier 1；其余列为探索候选。任何层级都不表示机制或临床效用。
- 主要候选数量上限预设为20个，以减少A1/A2后续多重检验负担。超过时按稳定入选频率、外部方向一致性、DE效应量绝对值依次排序；不得按最小P值或单队列AUC单独排序。

### 3.6 模型性能与外部验证
- 内部性能来自外层折外预测；报告ROC-AUC、PR-AUC、balanced accuracy、灵敏度、特异度、混淆矩阵、Brier分数及95%置信区间。以患者为bootstrap单位重采样1000次。只报告随机训练/测试拆分内的结果不可作为最终性能。
- 外部测试在冻结模型、基因列表、转换/标准化参数和分类阈值后一次性进行。阈值在训练折内选择（Youden只可作次要描述；主阈值基于预先指定敏感度或0.5概率），不可在外部集优化。跨平台时先验证探针映射和尺度可比性；不能可靠转换则只做单基因方向验证，不给模型AUC。
- 每个外部队列分别报告有效n、类别数、缺失特征、平台和所有性能指标；不把同一患者的多个数据集当不同验证队列。多个独立外部队列的方向一致性应逐个列出，不合并出一个更漂亮的AUC。

### 3.7 与A1/A2交接
输出候选基因、来源队列、各算法选择频率、DE log2FC/q值、模块编号/关联、外部表达方向、外部判别性能及限制。A1用于候选基因的单基因表达/预后/共表达等独立验证；A2仅负责批量组织候选及多重检验。B5不复制A1/A2的单基因生存分析，也不以“机器学习入选”替代临床效应验证。候选在新数据分析前冻结版本和名单。

## 4. 预登记判定规则
1. 主要终点为外层折外肿瘤/非肿瘤分类AUC，主要候选稳定性按患者级重复嵌套CV计算；主要基因级筛选家族为训练折内所有合格表达基因，报告BH q值。
2. DE候选门槛：q<0.05、|log2FC|≥0.5；WGCNA模块需q<0.05；ML稳定选择频率≥0.70，ML交集至少2种算法。未达门槛则降低证据等级，不更改阈值追逐交集。
3. 外部方向一致定义：在有可比肿瘤与非肿瘤对照的独立队列中候选方向与发现集一致；若外部q值不显著但方向一致，写“方向一致、统计证据不足”，不得写验证成功。
4. 分类器最低迁移参考：外部AUC≥0.70且95%CI下限>0.50，同时balanced accuracy≥0.60；否则记为未达到当前操作标准。若外部样本太少以致区间过宽，结论为证据不足，不以单一AUC解释。
5. 队列可访问性、标签定义、候选数、模型、调参空间、随机种子及排除理由先写入预注册文件；看见外部标签性能后修改即视为探索性更新，并保留原版本。
6. 发现队列中不允许因候选效应方向不满意而筛除病例。任何病例排除必须依据预先记录的样本类型/数据质量规则并报告流程。

## 5. 对照与稳健性检查
- **重复嵌套CV：**至少5次重复外层交叉验证，检查被选基因名单与AUC分布。报告每次折外预测，不以单次最好拆分作为结果。
- **标签置换阴性对照：**在患者级打乱组织标签，完整重跑特征筛选与嵌套CV至少200次；置换后性能分布应回到机会水平。若仍高，优先排查重复患者、泄漏和批次/标签混杂。
- **批次敏感性：**检查标签与中心、平台、批次是否完全混杂；能分层的批次在训练折内校正。对配对与非配对分析分别报告。不得先对全数据做监督式批次校正再拆分。
- **算法稳定性：**比较LASSO lambda.1se/min、RF置换/Gini重要性（后者只敏感性）、SVM-RFE不同合理特征数网格、WGCNA参数；若核心候选频繁变化，明确结果不稳定。
- **候选基准对照：**比较仅DE、DE+WGCNA、DE+三分类器集成三种筛选方案的候选规模、外层性能及外部方向；防止增加算法只增加候选筛选自由度。
- **混杂/组织成分：**有纯度、分期、病因字段时，评估候选与纯度/批次/病因关联；在可行情况下作调整或分层敏感性分析。组织类型能被批次完全预测时，不解释模型性能为疾病生物学。

## 7. 结果解释边界
- 可称“多方法筛出的候选基因”或“在独立表达队列中方向/判别表现获得支持”。
- 不可称“关键驱动基因”“治疗靶点”或“临床诊断标志物”，除非另有功能实验、前瞻性临床验证和适当的临床效用评估。
- LASSO、RF、SVM-RFE都以输入标签为目标；算法共识不构成独立生物学证据，模型性能不意味着因果。
- TCGA肿瘤与癌旁分类器的AUC不能直接外推到一般人群筛查、早期诊断或病理辅助诊断。
- 预测性标志物必须有接受不同治疗方案的患者队列并检验标志物×治疗交互；药敏数据库推断不能替代治疗响应验证。

## 8. 必须报告的局限
1. 多算法取交集容易产生“算法投票”错觉；算法间相关性高，交集稳定不等于独立重复。
2. HCC肿瘤/癌旁分类容易被肿瘤纯度、慢性肝炎、肝硬化及样本处理差异驱动；癌旁并非健康人群。
3. TCGA-LIHC样本量相对许多肿瘤队列较大，但对高维特征选择仍不足以支持任意复杂模型；验证数量与类别定义影响区间宽度。
4. GEO微阵列与RNA-seq的动态范围、探针注释和归一化不同，跨平台模型可迁移性不是自动成立。
5. WGCNA的模块依赖样本组成和参数；在肿瘤与癌旁混合数据上可能仅捕获组织类别差异。
6. 特征选择重复性、候选稳定性和外部性能必须分开报告。单次LASSO非零系数或RF重要性不是稳定的生物学排序。
7. 公开数据存在患者重复、病例选择、缺失临床资料及后验分析偏差；访问限制也可能使某个拟定外部队列不可用。

## 9. 失败处理与停止条件
- 病理组织类型、癌种或患者ID不清：标记待定并从主分析排除；不根据文件名猜标签。
- 外层折无法保证每类患者数、或发现HCC肿瘤样本<80：停止多算法预测；仅报告差异/描述统计并说明探索性。
- 病例标签与测序中心/平台完全混杂且无可识别设计：停止分类器推断，报告不可识别；不得靠ComBat制造可分信号。
- 某一队列外部患者重复、或曾参与候选筛选/调参：不得称独立验证，改作开发敏感性分析。
- 特征映射失败超过20%、外部对照类别缺失或标签定义不一致：不报告外部诊断性能；可保留单基因方向检查并注明证据范围。
- 标签置换后AUC系统高于机会、训练折表现远优于折外结果、或候选名单跨折极不稳定：先查泄漏/混杂；无法排除时停止模型结论。
- 外部性能未达到预设参考线：不再在外部队列调参；报告失败或证据不足。
- iCCA样本未达第2节门槛：停止iCCA机器学习，不能因B5名称而合并HCC与iCCA扩大样本量。

## 10. 验收标准
1. 队列清单可逐患者追溯，病理/组织标签和重复样本已审计，训练、锁箱、外部队列边界明确。
2. 任何差异筛选、WGCNA、缩放、特征选择与调参均在训练折内部拟合；折外预测和外部测试可重算。
3. DE、WGCNA、LASSO、RF、SVM-RFE各环节分别报告参数、结果规模和失败情况；有明确候选证据等级及冻结名单。
4. 报告重复嵌套CV、患者级标签置换、算法与批次敏感性分析，不只提供最好一张ROC图。
5. 外部验证明确独立性、平台映射、类别构成、样本数、置信区间及每基因方向；不适用时写明停止原因。
6. 至少复现一个公开HCC多方法研究的流程结构作为方法学对照。Zheng等报告用三套HCC表达数据，DE/WGCNA得到396个候选签名，再经RF/LASSO选出5个标志基因EFHD1、KIF4A、UBE2C、SMYD3、MCM7；文中分类分析AUC包含0.77–0.97。该组数字仅为论文报道的检索锚点，不能作为本项目结果，也不作为无泄漏/独立验证的保证；复现前须按全文和补充表核对数据拆分与候选筛选边界。
7. 交给A1/A2的候选清单包含版本、证据来源和解释限制，且不得把筛选结果包装成已验证治疗靶点。

## 12. 关键决定表

| 决定 | 采用规则 | 理由 |
|---|---|---|
| 主癌种 | 成人原发HCC；iCCA只有达到独立门槛才单独复制 | 避免混癌种与小样本扩大表观性能 |
| 主终点 | 肿瘤/非肿瘤表达分类 | 与“候选基因筛选”用途一致；生存需另立方案 |
| 主训练数据 | TCGA-LIHC，外部优先GSE14520，经审计后可用GSE76427/ICGC替补 | 公开数据较易取得，但确切病例数依当前样本核查 |
| 入选策略 | DE/WGCNA提供生物统计证据；LASSO/RF/SVM-RFE在患者级嵌套CV内重复筛选 | 降低单次拟合过度依赖与全数据预筛泄漏 |
| 候选层级 | 频率与独立外部方向/表现共同决定；最多冻结20个主候选 | 控制多方法叠加后的候选膨胀并便于A1/A2验证 |

| 实际结果状态 | 当前只写流程，不运行新的生物学显著性分析 | 仓库任务二交付物是AI可执行说明书，不是结果报告 |

- 待定：项目方最终希望筛选的表型/目标基因范围尚未指定。本版采用HCC肿瘤与非肿瘤表达判别；若要筛生存/药物响应，应单独冻结终点和数据。
