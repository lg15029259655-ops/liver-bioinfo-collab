# 说明书：B2 胆管癌 RNA 剪接分析（RBM39–EZH2）

## 0. 基本信息

- 清单编号：B2；类别：二（需要先核实可用剪接数据）。
- 日期：2026-11-20。
- 状态：文档方案可执行；胆管癌样本映射、目标事件覆盖和小样本限制须在下载审计后确认。
- 范围：只用他人处理好的 PSI/剪接事件矩阵或剪接计数；本任务不下载 FASTQ、不做原始 reads 比对，也不声称完成生物学分析。
- 项目定位：围绕 RBM39 与 EZH2 的候选剪接变化，检验公开胆管癌队列中 RBM39 表达与剪接事件 PSI 的关联；不能用观察性肿瘤样本证明 RBM39 导致剪接变化。

## 1. 要回答什么问题

在公开胆管癌肿瘤样本中，RBM39 表达是否与 EZH2 的候选外显子跳跃/内含子保留事件相关？若候选事件不在公开 PSI 矩阵中，胆管癌全事件 PSI 中是否存在与 RBM39 表达相关的探索性事件？

本方案回答的是患者肿瘤中的横断面关联，不能替代 RBM39 敲低/救援实验；组织样本中的共变也可能由肿瘤纯度、亚型、批次或其他转录调控因素造成。

### 2.1 样本清点和配对

建立 `B2_sample_manifest.tsv`，每行一个 TCGA 样本，至少包括患者 barcode、样本 barcode、样本类型、PSI 文件版本、表达文件版本、RBM39 表达值、有效 PSI 事件数、临床匹配状态和纳入/排除理由。一个患者如有多个肿瘤 aliquot，按 TCGA sample type 和 aliquot 规则预先选取一份；如不能判断重复关系，停止该患者的关联分析并在 manifest 中标待定。

以患者为独立统计单位。不得把同一患者的多个 aliquot 或重复样本当成独立患者。主分析只用肿瘤样本，不将癌旁、转移或复发样本混入主分析。若条码和样本类型无法可靠对应，停止，不按行顺序强行拼接。

### 2.2 主数据选择理由与限制

TCGA SpliceSeq 适合这项任务，因为它直接提供预计算的 PSI，而任务书限定不做原始 reads 比对。两篇 CCA 应用报告了相邻但不同的样本口径：一篇从 TCGA SpliceSeq 取得36例，按高缺失过滤后35例进入分组比较（PMID 34055632）；另一篇使用32例临床完整且 OS>90天的病例开展生存分析，并报告38,804个事件（PMID 31611977）。这些是两篇论文的复现锚点，不是本项目应得到的确切样本数或结果。

TCGA-CHOL 队列很小；它可用于目标事件可行性和探索性关联，不适合在本项目中训练并宣称一个稳健的全基因组剪接风险模型。数据下载后若有多个数据版本，以记录了日期、来源和校验值的本次文件为准。

## 3. 分析步骤

### 3.1 文件审计和标准化

1. 从 TCGA SpliceSeq 下载 TCGA-CHOL PSI；优先下载全部事件类型（AA、AD、ES、RI、AP、AT、ME），若文件过大按事件类型分次下载。保存原始压缩文件、下载日期、查询条件和 SHA-256。
2. 记录 SpliceSeq 事件 ID、基因符号、事件类型和 PSI 样本列；事件 ID 不只靠基因名识别。将 TCGA barcode 解析到患者级，并与表达矩阵、临床表逐项核对。
3. PSI 应在 [0,1]。越界值、非数值字符串或重复事件 ID 单独列出；禁止静默截断或平均重复项。缺失值保留为 NA，不按0填补。
4. 对每个事件统计可用患者数、PSI 缺失率、取值范围和标准差；记录 RBM39 表达尺度，若有多个表达版本，主分析只选一版并锁定。

### 3.2 候选事件优先分析

主要候选：团队机制论文提出的 EZH2 exon 14 skipping 和 intron 10/11 retention。先从论文图/补充资料核实事件边界、基因组版本、转录本方向和 PSI 的 inclusion 定义，再映射到 TCGA SpliceSeq 事件 ID。

- 若候选事件可唯一映射且在至少20名匹配患者中有 PSI 与 RBM39 表达：以连续 RBM39 表达与事件 PSI 的 Spearman 相关为主，双侧检验；对 EZH2 预先列出的多个事件作 BH 校正。报告 rho、患者数、P、q、缺失比例和区间估计。
- 方向性解释只有在核实“高 PSI 对应该事件的包含型/跳跃型转录本”后才进行。否则报告无方向假设的双侧关联，不把 PSI 高低直接翻译成 exon inclusion/skipping。
- 对应文章的 RBM39 敲低发现可作为预先提出的方向假设：敲低时某些 EZH2 剪接异常上升；但是只有事件定义相同并且 PSI 方向可对应时才比较方向。关联结果不能写成验证了敲低机制。
- 若任一事件无唯一映射、覆盖不足20人或注释不充分：将该事件标为“当前公共矩阵不可评价”，不换用相似事件代替、不根据关联显著与否修改事件定义。

### 3.3 全事件探索分析（次级）

仅在 PSI 与表达的患者映射通过后，逐事件计算 RBM39 连续表达与 PSI 的 Spearman 相关。一个事件至少有20个非缺失的患者配对值才进入统计；该20例是本版保守工作门槛，不是文献保证充分效能的公认样本量标准。全事件集合在分析前依据有效性过滤规则一次锁定，对该集合的全部 P 值统一做 BH 校正。

全事件分析只用于提出候选，不用于训练预测模型。报告全部事件的效应、P/q、有效 n 和检测率，不只挑 q 值较小或符合预期的条目。若 n<20，仅给覆盖与 PSI 分布，不作显著性结论。

### 3.4 竞争解释和表达协变量

主关联分析不以高/低表达中位数二分 RBM39，因为连续表达保留信息且可避免阈值选择。作为敏感性分析可画散点和 LOWESS 趋势，但图形不用于挑选检验方法。若公共临床元数据提供足够完整的肿瘤纯度或批次变量，另做探索性调整模型；没有可靠字段时不自行补值，主结果明确为未调整关联。

## 4. 预登记判定规则

- 主问题：候选 EZH2 事件的 PSI 与 RBM39 表达相关；候选列表与事件 ID 映射表在查看关联结果前冻结。
- 主要检验：候选事件集合内 Spearman 相关、双侧检验、BH 校正；报告 rho 和不确定性，不只报告显著性。
- 次级检验：经 PSI 完整率和样本数过滤后，对所有可评价事件一次性进行 Spearman 相关并在全事件家族内 BH 校正。
- 探索性支持阈值：q<0.05 且绝对 rho≥0.30 作为工作约定，同时报告未过阈值结果。样本量小，不能把该阈值称为临床验证门槛。
- 对候选事件覆盖不足、barcode 不匹配或事件方向无法映射时，结果定为不可评价，不用替代事件追求显著性。
- 不论有无统计信号，均不得写“RBM39 导致剪接变化”或“证实 RBM39–EZH2 机制”；机制结论需要干预和转录本验证。

## 5. 对照与稳健性检查

1. **样本一致性**：比较 PSI、表达、临床样本的患者 ID 集合；输出左/右未匹配清单及原因。
2. **异常值**：画 RBM39 表达与候选 PSI 的散点图，标注患者 ID 匿名条码；报告 Spearman 相关对极值的稳健性。不得因删样后显著而选删样模型。
3. **阈值敏感性**：全事件覆盖阈值至少比较预登记主规则与更严格覆盖规则；每种规则下的事件数和检验家族都单列。只作为稳定性检查，不择优报告。
4. **患者重复**：按患者聚合后保证每患者一行；若保留多样本敏感性，则用患者聚类/混合模型，并仅在方法与样本数支持时进行。
5. **技术与生物学混杂**：按可获得的批次、肿瘤纯度、分子亚型作描述；不把缺失字段默认为无混杂。
6. **已发表锚点**：复核既往 CCA SpliceSeq 论文所述事件总量与其样本筛选逻辑；对差异不通过改变筛选阈值追数值。原文大范围生存签名并非本方案主要终点。

## 7. 不能声称

- 不声称跑过原始测序数据、STAR 比对或 rMATS；本方案用的是预计算 PSI 矩阵。
- 不声称 TCGA-CHOL 的有限样本可代表所有胆管癌亚型、不同地域或治疗人群。
- 不把 PSI 关联说成 RBM39 的因果调控，也不把表达相关当作敲低实验复现。
- 不把 E-MTAB-6389、GSE107943、GSE76297 的表达矩阵当成可用 PSI 的剪接数据。
- 不把在同一 TCGA 小队列中探索出的关联称为外部验证或临床预测模型。
- 不照搬论文中未经本项目数据重算的显著事件、HR、AUC 或通路结果。

## 8. 必须报告的局限

1. TCGA-CHOL 患者数有限，且队列有取样和亚型构成偏倚；全事件检验功效不足、估计不稳定的风险较高。
2. SpliceSeq PSI 是基于 TCGA RNA-seq 的预计算事件指标；本方案无法检查 FASTQ 层面的比对质量、junction read 支持和批次校正细节。
3. 公开 PSI 的事件定义/基因组版本可能与团队细胞实验报告的 EZH2 exon/intron 边界不同，事件映射失败时只能报告不可评价。
4. RBM39 表达、肿瘤纯度、细胞组成和剪接共同变化可能造成混杂；横断面关联无法建立方向或因果。
5. 团队 RBM39 机制研究生成的实验 RNA-seq 数据目前未见公共 accession；没有该数据就不能在相同细胞模型中复现原始剪接发现。

## 9. 失败与处置

| 情况 | 处置 |
|---|---|
| TCGA SpliceSeq 无 CHOL 当前数据或下载失败 | 记录访问日期/错误；不转用论文汇总数字；暂停主分析 |
| 表达与 PSI barcode 无法患者级匹配 | 暂停，不按样本顺序拼接 |
| EZH2 事件边界或 PSI 方向不能唯一确定 | 将候选主检验标为待定/不可评价；可报告事件覆盖，但不作方向性解释 |
| 主目标事件有效 n<20 | 只报告描述统计与覆盖情况，不作确认性统计结论 |
| 全事件候选结果随过滤规则变化明显 | 报告不稳定，列出各规则结果，不选择显著性最好的一套 |
| 公开外部数据没有剪接事件/PSI | 外部剪接复现停止；表达层验证必须分开命名 |
| 研究者拿到作者生成的处理矩阵 | 先查数据许可、分组、重复数、事件定义和处理版本；单独立方案版本，不自动并入 TCGA 分析 |

## 10. 验收标准与复现锚点

- **数据验收**：TCGA SpliceSeq 官方下载页能导出 TCGA-CHOL 按样本 PSI 表；提供下载条件、时间、文件哈希和样本清单。官方页面声明提供各癌种逐样本 PSI 值。此次不把网站所称“已加载”误写成已下载或已分析。
- **队列锚点**：PMID 34055632 报告36例 TCGA-CHOL 剪接数据、排除1例高 PSI 缺失后35例分析；PMID 31611977 报告32例临床完整且 OS>90天病例和38,804个事件。二者筛选口径不同；我们的样本数或事件数不同，应核对版本、条码、临床过滤和事件过滤，不要求硬复现相同数值。
- **方法锚点**：同一应用研究报告在32例中使用七类剪接事件 PSI；团队 RBM39 研究报告了 EZH2 exon 14 skipping 与 intron 10/11 retention 的细胞实验线索。前者支持公开队列可行性，后者支持目标假设，二者用途不同。
- **统计验收**：所有目标事件都能追溯到唯一事件 ID、PSI 方向、barcode 配对和有效样本数；全事件 P 值校正范围明确；结果表包含阴性、不可评价事件。
- **分析状态**：本说明书只完成方案和公开数据来源审计；尚未下载/运行 TCGA PSI，也没有本项目效应估计、P/q 值或通路结果。
