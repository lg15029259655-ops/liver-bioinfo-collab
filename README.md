# 肝癌与胆管癌生信分析：合作仓库

这个仓库只放**文档**，用来和合作者交接："要做哪些分析"和"每个分析怎么做"。

## 先读（按顺序）

1. `docs/TASK_FOR_COLLABORATOR.md`：**你的任务书**，从头读到尾。
2. `docs/PRIORITY_LIST.md`：要做的分析清单，排好序。
3. `docs/MENU_OF_EXISTING_TOOLS.md`：现有 8 个分析工具能做什么、有什么局限。
4. `docs/TEAM_PAPERS.md`：两个团队的论文清单，作为找文献的起点。
5. `docs/GITHUB_UPLOAD_GUIDE.md`：怎么上传你写的东西。

## 你写的东西放哪里

| 文件夹 | 放什么 |
|---|---|
| `topics/` | 课题卡 |
| `frameworks/` | 分析说明书，和 `QUESTIONS.md`（你的疑问） |

**只改这两个文件夹，不要改 `docs/`。** 不要上传数据文件、论文 PDF、代码，或任何密码和个人信息。

上传方法：用浏览器，"Add file → Upload files"，提交时选 "Create a new branch for this commit and start a pull request"。一个拉取请求只放一个分析。详细步骤看 `docs/GITHUB_UPLOAD_GUIDE.md`。
